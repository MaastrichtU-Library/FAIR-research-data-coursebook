# FAIR Research Data Coursebook

This repository is being migrated from the archived Carpentries lesson-template
infrastructure to [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).

## Current Branch

The `workbench` branch is the active migration branch.

## Migration Status

- Workbench template infrastructure has been added.
- Legacy lesson source has been preserved under `legacy/styles-src/`.
- The homepage, setup page, reference page, and instructor notes have been
  migrated into Workbench structure.
- `episodes/introduction.md` has been rewritten as the first Workbench-native
  episode.
- The remaining episodes have been copied into `episodes/` and will be
  converted incrementally.
