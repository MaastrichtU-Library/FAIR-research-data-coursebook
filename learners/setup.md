To follow the coursebook effectively, learners should prepare a small set of
accounts and familiar tools before starting.

## Recommended Preparation

- Create a [GitHub account](https://github.com/).
- Review a short introduction to [Markdown][markdown-guide] and GitHub Pages.
- Create a [DataverseNL account][dataversenl]. If you are outside the
  Netherlands, use [Harvard Dataverse][harvard-dataverse].
- Join the lesson Slack workspace if it is still being used for your delivery
  format.
