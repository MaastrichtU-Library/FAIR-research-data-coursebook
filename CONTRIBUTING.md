# Contributing

Contributions to this lesson are welcome.

## How to Contribute

- open an issue for factual errors, broken links, or unclear explanations
- propose focused content changes through pull requests
- keep lesson edits small and easy to review

## Working Branch

The active lesson source is maintained on the `workbench` branch.

## Expectations

- follow the [Code of Conduct](CODE_OF_CONDUCT.md)
- preserve lesson clarity and accessibility
- prefer practical, reviewable changes over large unrelated rewrites
