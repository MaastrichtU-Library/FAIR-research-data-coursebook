# FAIR Research Data Coursebook

This repository is being migrated from the archived Carpentries lesson-template
infrastructure to [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).

The coursebook teaches FAIR implementation through practical examples rather
than theory-heavy exposition.

## About

The lesson is organized around six recurring FAIR data tasks:

1. Set up your own terms
2. Speak the same language
3. Securely share
4. Publish and preserve
5. Make machines work for you
6. Responsibly reuse

## Migration Status

This `workbench` branch now uses the Workbench repository structure.

- The old lesson source has been preserved in `legacy/styles-src/`.
- The homepage, setup page, reference page, and about page have been migrated.
- The introduction episode has been rewritten in Workbench syntax.
- The remaining episodes are staged in `episodes/` and will be converted one by
  one.
